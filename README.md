## 📌 What this is

A tweet sentiment classifier (**negative / neutral / positive**) built from scratch with
TensorFlow/Keras, comparing three recurrent architectures — **SimpleRNN**, **LSTM**, and
**GRU** — head-to-head on the same train/val/test split, plus a small Streamlit app for
live predictions.

<div align="center">

| 🧠 Model | 🔁 Layer Type | 🎯 Test Accuracy |
|:---:|:---:|:---:|
| SimpleRNN | Bidirectional SimpleRNN ×2 | ~55% |
| **LSTM** ⭐ | Bidirectional LSTM ×2 | **68.4%** |
| GRU | Bidirectional GRU ×2 | ~64% |

*(exact numbers depend on the training run — see the notebook's comparison chart for the current results)*

</div>

> ⚠️ **Honest note on accuracy:** this dataset (Kaggle's *Tweet Sentiment Extraction*) has 3
> classes and very short, informal tweets. Published RNN/LSTM/GRU-from-scratch benchmarks on
> this dataset typically land around **65%–78%**. A 90%+ target realistically needs either a
> 2-class setup or a pretrained Transformer (BERT/DistilBERT) instead of RNN/LSTM/GRU.

## 🧩 Model Architecture

Every model shares the same skeleton so the comparison is fair — only the recurrent layer changes:

```
Input (padded sequence, len 40)
        │
        ▼
Embedding (trainable, dim 128)
        │
        ▼
Bidirectional [SimpleRNN | LSTM | GRU]  (64 units, return_sequences)
        │
        ▼
Bidirectional [SimpleRNN | LSTM | GRU]  (32 units)
        │
        ▼
Dropout (0.5) → Dense (64, relu) → Dropout (0.3)
        │
        ▼
Dense (3, softmax) → negative / neutral / positive
```

Training uses **class weights** (to offset the neutral-class majority), **EarlyStopping**,
and **ReduceLROnPlateau**.
